Before you install

Files are processed locally. This package adds only PDF Free For All.app to Applications; it has no background services, extensions, or installation scripts. Your documents and default PDF app are not changed.

An administrator may need to authorize installation. Open the installed app from Applications or Spotlight after installation. No restart is required.

PDF to Word exports selectable text; scanned pages need OCR, which is not included. Complex Word layouts may differ. macOS 13 and earlier are not supported.

Signing status

This local preview is not signed with an Apple Developer ID and has not been notarized by Apple. macOS may block installation or launch when the file is downloaded from the internet. This package is not yet an Apple-verified public release. Do not disable macOS security protections.
